# Contributing

Thank you for taking an interest in Trindle screen reader. A screen reader is only as good as the people who test it, so a clear report is worth a great deal.

## Reporting a bug

Report bugs and crashes on the [Buildmorphic community](https://buildmorphic.com) first; GitHub issues are also welcome. Please say:

- what you did
- what you expected to happen
- what happened instead
- the version, the programs involved, and how you start the reader

If the reader said something wrong, or failed to say something, the exact words help most. The reader's log is in `$XDG_RUNTIME_DIR/trindle-screen-reader/log`. Look it over before pasting it.

## Security problems

Please do not report these in public. Read [SECURITY.md](SECURITY.md) and use the private route there.

## Code changes

Code changes are not taken as pull requests. That is simply how the project is set up, because the reader has to be trusted by people who cannot check what it is doing. A description of the problem is the most useful thing you can send, and it will be looked at.

You are free to fork the project under the terms of the licence and take it in your own direction.
